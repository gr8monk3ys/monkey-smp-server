      Console

      Commands run as the server console. To stop or restart the server, use the Server tab. The lines the game logs each time a scheduled job connects (RCON) are left out; Files, logs has the whole file while it is under 2 MB.

      Files

      The server's own folder. Worlds, libraries and databases are not shown. Every change is kept in history, so a save or a delete can be undone.

          Players

          Banned addresses

          Bans an IP address, so nobody can join from it under any name. Type a public IPv4 or IPv6 address, or the name of a player who is online to ban the address they are on. A private or local address is refused: it could be a proxy's, and banning it would keep everyone out.

              Backups from here

              The backup helper isn't installed, so backups can't be started or restored from here. The owner installs it once on the machine: sudo sh /srv/monkey/repo/deploy/monkey-staff.sh --install-helper

                Only an owner can restore, and types the snapshot's short ID to confirm. The world as it was is kept on the machine, in backups/before-restore-TIME.

                What the helper did last

                  Download the world

                  A zip of the whole world folder, for keeping or testing at home. Owners only, one at a time.

                  Version

                  Switching needs the root helper (the owner's step: --install-helper).

                  Java and memory

                  Up to 20, like -XX:MaxGCPauseMillis=100 or -Dfile.encoding=UTF-8. The start script's own tuned flags stay; these come after them. Only garbage-collector and JIT tuning (G1..., MaxGCPauseMillis, ...) and a few plain properties: anything else goes in on the machine.

                  Takes effect at the next restart. A bad flag can stop the server starting: clear it here and start again. The old settings are kept in staff-removed/ on the machine.

                  Reset the world

                  A new world, with a new seed if you give one. The old world is kept on the machine, never deleted. The seed is never shown or logged.

                  Upload a world

                  A .zip of a world folder (level.dat at the top or one folder in), up to 8 GB. It is checked when it arrives and changes nothing until you swap it in; the live world is kept on the machine first.

                  SFTP

                  No SFTP login is set up: ask the owner. Each login is key-only and sees only the server folder.

                  Timed jobs on the machine

                  The machine's own jobs: the daily restart, backups and deploys. Change them on the machine.

                      Users

                      The logins of the page's own login page. Owners only: the last owner can't be demoted, disabled or deleted.

                      Settings

                      server.properties as a form. Most changes take effect when the server restarts (Server tab). Ports, RCON, the seed, the world's name and online mode are locked here. Every save keeps the old file in Files, history.

                      No unsaved changes.

                      Server icon

                      The picture next to the server in the players' list: a 64 by 64 pixel PNG. It shows after the next restart.

                      No icon: players see the default.

                      Game rules

                      Read from the running server. A change takes effect at once, no restart. The launch, Truce Hour and season events switch some rules themselves (pvp, portals) and may switch them back.

                      Mod settings

                      Each mod's config file as a form, with the file's own comments as help. A save changes only the values you changed: every comment and line order stays. Most changes take effect when the server restarts (Server tab). Every save keeps the old file in Files, history, and goes in the record of changes.

                      Strength SMPin-game settings, over RCON

                      No config file: these live in the world. A change needs no restart and stays after one. A new cooldown or lifetime counts from the next ultimate: one already running keeps its old time. Times are in seconds (about). The start level, the level range and the mace and lunge cooldowns are fixed in the mod and can't be changed here.

                      Mods

                      The mods in the server's mods folder, read from each jar. Admins can add, turn off and remove them here; each change asks you to type the jar's name, and every old jar is kept in mods-removed/ on the machine.

                      Before you change a mod: a mod that players need too must match in their mod pack, or they can't join. The release's own (pinned) mods come back each time the server starts, and the next release deploy puts the mods folder back to that release's list. A change takes effect when the server restarts.

                      Upload a jar

                      A Fabric jar of up to 64 MB. Client-only mods are refused: they go in the players' pack. Only the owner can upload a jar, because a jar runs as the server.

                      Find one on Modrinth

                      Only the owner can upload a jar or install a modpack: a jar runs as the server. Modrinth files are checked against Modrinth's hash.

                        Install a modpack

                        A Modrinth .mrpack for this game version and Fabric, up to 64 MB. Its server mods are downloaded and checked first; only if every one passes are they put in the mods folder. Client-only mods and the pack's config files are skipped. Only the owner can install a pack.

                        Installed mods

                          Data packs

                          The world's datapacks folder. A new pack is turned on when you press Reload or the server restarts. The release's own packs come back at every start, so they can be turned off but not removed.

                          To find a pack that causes trouble: Turn all off saves which packs are on, then turns them all off. Turn them back on one at a time, then Turn saved set back on puts the rest back in their old order.

                            Look, don't touch: nothing on this tab can change the server. The other tabs can, and every change is logged with your name. Please keep the address and your password to yourself.
