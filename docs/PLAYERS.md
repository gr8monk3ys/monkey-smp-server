# Joining The Realms

## What you need

- **Minecraft Java Edition** (not Bedrock / Windows 10 Edition). Version **26.1.2**.
- Your Minecraft username on the server's **whitelist**. Ask the host to add you.
- The server address from the host (for example `something.joinmc.link`).

## Option A: plain Minecraft (simplest)

1. In the Minecraft Launcher, make an installation for release **26.1.2** and start it.
2. **Multiplayer > Add Server**, paste the address, **Done**, then join.

## Option B: the full experience (recommended)

The client pack adds shaders, nicer textures, smoother performance, a minimap, voice chat and more.

1. Install [Prism Launcher](https://prismlauncher.org/download/) (free) and sign in with your Microsoft account.
2. Download **`TheRealms-Client-<version>.mrpack`** from the [latest release](https://github.com/gr8monk3ys/the-realms-server/releases/latest).
3. In Prism: **Add Instance > Import**, choose the `.mrpack`, **OK**. It downloads everything (a few minutes).
4. Launch it, then **Multiplayer > Add Server** with the address from the host.

The Modrinth App can also import `.mrpack` files.

**Performance:** shaders are heavy. If it stutters, press **O** in-game (Iris shader menu) to pick a lighter
profile or turn shaders off, and lower **Video Settings > Render Distance**.

**Voice chat:** press **V** to open Simple Voice Chat settings. Proximity voice works out of the box.

## Playing

- `/tan`: Towns & Nations. Create or join a town, claim land, form nations and alliances, declare wars.
- `/spawn`, `/sethome`, `/home`, `/tpa <player>`: getting around.
- `/msg <player>`, `/pay <player> <amount>`, `/balance`.
- **Spawn is a safe zone**: no PvP or explosions. Outside it, PvP is on.
- Wars can only happen between **10:00 and 23:30** server time, and need 30 minutes' notice.
