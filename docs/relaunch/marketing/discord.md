# Discord layout for the relaunch

Draft for Lorenzo. Keep the existing server and invite (the plan says to announce there first), and reshape it for
a public, free server: fewer channels, a clear first five minutes, and the season up front.

## Onboarding

Use Discord's built-in Onboarding (Server Settings, Onboarding) so a new member picks what they see before the
channel list appears.

1. **Rules screening**: a short list a member must accept, the same six points as the site's Rules section, with a
   link to the full rulebook on the site.
2. **Question 1: "How do you play?"** Java / Bedrock (phone, tablet, Windows) / Console. Each gives a role and
   unlocks the matching join channel. Console gets the console how-to.
3. **Question 2: "What are you here for?"** (pick any) PvP and hearts / Trading and the economy / Building /
   Making videos. Each gives a ping role for that kind of news.
4. **Question 3: "Where did you hear about us?"** (optional) TikTok / YouTube / A creator / A server list / A friend.
   Each gives a hidden role, so the member list shows which channels bring people in now that the server no
   longer counts joins by address.
5. **Default channels**: #start-here, #announcements, #general, #trading.
6. **Server guide welcome**: "Welcome to the jungle. Mind your hearts." with three to-dos: read #start-here, join the
   server, say hi in #general.

## Channels

**START HERE**
- `#start-here`: read-only. What Monkey SMP is in three lines, both addresses, the Season 1 date, links to the site,
  rules and store.
- `#announcements`: read-only, followable from other servers. Season dates, updates, downtime.
- `#rules`: read-only. Links to the full rulebook on the site rather than a copy, so there is one version.
- `#how-to-join`: read-only. Java steps, Bedrock steps, the console workaround.

**SEASON 1**
- `#season-news`: events, the border, the finale countdown. Pinged with @Events.
- `#hearts`: kill feed and heart-steal highlights (bot-fed if the server sends it, otherwise player posts).
- `#leaderboards`: weekly richest, most hearts, Server Firsts.

**COMMUNITY**
- `#general`
- `#trading`: buy and sell for in-game money only. Pinned: no real-money trades.
- `#clips`: players' own clips. The best go into the weekly recap.
- `#builds`
- `#memes`
- `#looking-for-team`

**HELP**
- `#help`: a forum channel, one post per question, with tags Java, Bedrock, Console, Store, Bug.
- `#bug-reports`: a forum channel. Dupes go to staff privately (a ticket), never in public.
- `#suggestions`: a forum channel with up and down reactions.
- `#tickets`: a ticket bot for reports, appeals and store problems.

**VOICE**
- `Lounge`, `Squad 1`, `Squad 2`, `AFK`

**CREATORS** (only @Creator)
- `#creator-hub`: event dates ahead of time, creator code questions.

**STAFF** (only staff)
- `#staff-chat`, `#staff-log`, `#reports`, `#appeals`
