# Monkey SMP marketing assets

Logo, banners and trailer for advertising the server. Everything here is generated by the scripts in
this folder, so a change is an edit and a re-run, not a redraw.

## What's here

| Path | What |
|---|---|
| `logo.py` | The pixel grids (16 x 16 monkey, 7-row pixel letters) and the palette. Writes `logo/*.svg`. |
| `logo/mark.svg` | Master mark: the monkey on a green tile. Also `site/favicon.svg`. |
| `logo/face.svg` | The monkey alone, no tile. |
| `logo/logo.svg` | Horizontal lockup: mark + MONKEY SMP. |
| `logo/logo-stacked.svg` | Stacked lockup, for square-ish spaces. |
| `logo/wordmark.svg` | MONKEY SMP alone. |
| `logo/png/` | `mark-512/256/128/64.png`, `logo-696w/1392w.png`, `logo-stacked-704w.png` (transparent). |
| `server-icon.png` | 64 x 64 Minecraft server-list icon. Copy it next to `server.properties` on the live server. |
| `banners/` | The two small banners: `server-list-468x60.png` and `discord-banner-960x540.png`. |
| `build.py` | Renders `logo/png`, `server-icon.png`, every banner and `site/img/og.jpg`. |
| `music.py` | Synthesises the trailer music (numpy + scipy, no samples). |
| `trailer.py` | Renders the trailer: Pillow frames piped into ffmpeg, with the music. |

The site also uses `site/img/og.jpg` (Open Graph / Twitter card, wired into `site/index.html`) and
`site/img/icon-256.png` (apple-touch-icon).
`site/media/` holds the 720p trailer and its poster (the logo-reveal frame), and `site/kit/` copies of the
logo PNGs and both banners for the site's "Spread the word" section. Copy them again after a re-export.

## Look

- Palette from the site: pen green `#184e35`, paper `#f9f8f5`, ink `#1a1f23`; plus banana gold `#e8b23a`
  for "SMP" and calls to action. Fur and face tones are in `logo.py`.
- Type from the site: Fraunces Bold (headlines), Instrument Sans (body), IBM Plex Mono (addresses,
  kickers). The logo itself is pixel geometry, no font.
- Pixel art scales only by whole numbers: the mark is 16 cells, so 64/128/256/512 px are exact.

## Re-exporting

Needs Python 3.11 with Pillow, numpy and scipy, Inkscape 1.4 on `PATH` (it rasterises the SVGs) and ffmpeg.

1. Fonts (OFL, from google/fonts), once:

   ```sh
   cd D:/DevData/monkey-smp-marketing/fonts
   curl -LO "https://raw.githubusercontent.com/google/fonts/main/ofl/fraunces/Fraunces%5BSOFT,WONK,opsz,wght%5D.ttf"
   curl -LO "https://raw.githubusercontent.com/google/fonts/main/ofl/instrumentsans/InstrumentSans%5Bwdth,wght%5D.ttf"
   curl -LO "https://raw.githubusercontent.com/google/fonts/main/ofl/ibmplexmono/IBMPlexMono-Medium.ttf"
   python -m fontTools varLib.instancer Fraunces*.ttf wght=700 opsz=144 SOFT=0 WONK=0 -o Fraunces-Bold.ttf
   python -m fontTools varLib.instancer InstrumentSans*.ttf wght=600 wdth=100 -o InstrumentSans-SemiBold.ttf
   python -m fontTools varLib.instancer InstrumentSans*.ttf wght=400 wdth=100 -o InstrumentSans-Regular.ttf
   ```

2. `python marketing/logo.py` (only after editing the grids), then `cp marketing/logo/mark.svg site/favicon.svg`.
3. `python marketing/build.py`: logo PNGs, server icon, banners, OG image (about 30 s).
4. `python marketing/trailer.py --preview` writes a contact sheet (one frame per section) to check the
   cards; `python marketing/trailer.py` renders the MP4 (a few minutes).

Text lives in the scripts: taglines and the address at the top of `build.py`, the trailer's sections
(screenshot, pan, kicker, headline, sub) in `SECTIONS` in `trailer.py`, the Discord invite in `DISCORD`.
Keep the facts in step with `site/index.html` and `docs/RULES.md`.

## Trailer

Nine two-bar sections at 100 BPM, cut on the downbeat: logo reveal, then one hook each (a modded
factions server; factions of four; alliances and territory; Strength SMP; modded terrain and dungeons;
the Season I launch hour; one pass, same price), then the Discord and website. The motion is slow pans
over the in-game screenshots; no live gameplay footage was captured. Swap a section's screenshot for a
clip later by recording with the shaders on and replacing `pan()` for that section.

The music is made from scratch in `music.py` (additive saws, synthesised drums, A minor, Am F C G), so
there is nothing to license.
