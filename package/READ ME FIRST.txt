THE REALMS - how to run the server
==================================

A modded Minecraft (Java 26.3) factions server: parties, allies, land claims, PvP, new
structures, mobs and magic. You need: Windows 10 or 11, 16 GB of RAM or more (24-32 GB if
you also play on this PC), and about 10 GB of free disk space.
You do NOT need to install Java or anything else - this folder takes care of it.


1. FIRST TIME
-------------
  a) Put this whole folder somewhere permanent, like Documents (not Downloads).
  b) Double-click  "Start Server.bat".
     - If Windows says "Windows protected your PC", click "More info" then "Run anyway".
     - It downloads about 500 MB the first time (Java, the server and its 115 mods),
       and the first start builds the world, so give it 5-10 minutes.
  c) It asks you two things:
     - Do you agree to the Minecraft EULA?  Type  YES  and press Enter.
     - Your Minecraft username.  Type it and press Enter. You become the admin.
  d) If Windows Firewall asks about "Java", click "Allow".
  e) When the window says  Done (...)! For help, type "help"  the server is running.
     Keep that window open while people play.


2. EVERY TIME AFTER THAT
------------------------
  Start:  double-click "Start Server.bat".
  Stop:   click in the server window, type  stop  and press Enter.
          (or double-click "Stop Server.bat")
  Please don't just close the window - that can lose the last few minutes of the world.


3. LETTING FRIENDS JOIN
-----------------------
  Only people on the guest list (the "whitelist") can join.
  Add someone: double-click "Add Player.bat" and type their Minecraft username.
     (or type  whitelist add THEIRNAME  in the server window)

  Friends in the same house: they join with your computer's local address
  (shown as "IPv4 Address" when you run  ipconfig  in a Command Prompt).

  Friends somewhere else: use playit.gg (free, no router setup needed):
    1. Go to https://playit.gg, make a free account, and download the Windows app.
    2. Run it and follow its "claim" link to connect it to your account.
    3. In the playit.gg website, add a tunnel:  type "Minecraft Java",
       local address 127.0.0.1, local port 25565.
    4. It gives you an address like  something.joinmc.link  - send that to friends.
    5. playit must be running (along with the server) whenever people play.
    Voice chat (optional, needs one more tunnel):
    6. In playit.gg add a second tunnel: type "UDP" (or "Custom UDP"),
       local address 127.0.0.1, local port 24454. Note the address and port it gives you.
    7. Stop the server, open  server\config\voicechat\voicechat-server.properties  in
       Notepad, set  voice_host=THAT-ADDRESS:THAT-PORT  (e.g. 147.185.221.10:51234), save,
       and start the server again. Without this, everything works except voice chat.


4. WHAT FRIENDS INSTALL (everyone, including you)
-------------------------------------------------
  Plain Minecraft can't join: the server adds new blocks, mobs and items, so every player
  needs the mods. Send each player the file  TheRealms-Player-(version).zip  from the same
  release as this server. Inside it:
    - "Install for Minecraft Launcher.bat" sets everything up in the normal Minecraft
      Launcher (they then pick "The Realms" next to the Play button).
    - "READ ME.txt" explains it step by step, in plain language.
    - The .mrpack file is for people who already use the Modrinth App or Prism Launcher.
  Then they add your server address in Multiplayer > Add Server.
  Remember to add each player with "Add Player.bat" (or  whitelist add NAME ).


5. BACKUPS
----------
  Double-click "Backup World.bat" (works while the server runs).
  Backups go into the "backups" folder; the newest 14 are kept.
  To restore one: stop the server, then copy the files from a backup folder into "server".

  Automatic backups: double-click "Schedule Backups.bat" once. Windows then backs up the
  world at 6 AM and 6 PM while you're signed in (14 backups = the last 7 days).
  Each run is written to "scheduled-backups.log" in this folder: look there if the
  newest backup is older than it should be.
  A dead disk takes the world AND the backups with it, so every week or so copy the
  newest backup folder somewhere else (another drive, OneDrive, Google Drive...).
  Try restoring a backup once (into a copy of this folder) so you know it works.


6. ADMIN CHEAT SHEET (type in the server window, or in game with / in front)
-----------------------------------------------------------------------------
  whitelist add NAME            let someone join
  whitelist remove NAME         stop someone joining
  op NAME                       make someone a full admin
  lp user NAME parent set moderator    give someone the moderator rank
      ranks: default, builder, moderator, admin
  kick NAME / ban NAME          remove a troublemaker
  ledger rollback source:NAME range:20 after:1h   undo griefing (Ledger)
  stop                          save and shut down

  In game, players claim land on the map (press M, right-click chunks) and use
  /openpac-parties  to make parties and allies. Claimed land is protected.
  Near spawn only admins can build. PvP is on everywhere else.


7. IF SOMETHING GOES WRONG
--------------------------
  "The server is running. Stop it first"  - it's already open in another window.
  "Failed to bind to port"  - another server is already using port 25565.
  "This folder already has a ... server with a world in it"  - you unzipped 2.x over an
      old 1.x server.
      Unzip it into a new, empty folder instead (the old world stays where it was).
  Anything else: send the person who gave you this folder a screenshot of the window,
  plus the file  server\logs\latest.log

8. HOSTING ONLINE (so the server runs without your PC)
------------------------------------------------------
  You can run the same server on a Minecraft hosting company (Shockbyte, Apex,
  BisectHosting, any Pterodactyl panel) or on your own Linux server (VPS).
  a) Stop the server if it is running.
  b) Double-click  "Prepare for Hosting.bat". It downloads anything missing (it asks the
     same questions as Start Server the first time) and makes a zip in the "exports" folder.
  c) Open that zip and read  HOSTING.txt  - it explains how to upload and start it,
     step by step, for hosting companies, Docker and plain Linux.
  The world you play here is only included if it already exists; otherwise the host
  creates the same world (same seed) the first time it starts.


9. BEFORE A BIG GROUP JOINS (10 or more players)
------------------------------------------------
  Memory: the server picks it from your PC's RAM (8 GB on a 32 GB PC, 5 GB on 16 GB).
     8 GB is plenty for 25 players. To choose yourself, set it once in a Command Prompt:
        setx REALMS_MEMORY_GB 8
     then start the server from a new window.
  Players: up to 30 can be online (max-players in server\server.properties).
  Build the world ahead of time. New land is the main cause of lag when many people
  explore at once. With nobody online, type in the server window:
        chunky radius 5000
        chunky start
     It takes hours (leave it overnight); "chunky progress" shows how far along it is.
     Then stop players walking past the built area:
        worldborder set 10000
  Lag? Type  spark tps  for the server's speed (20 TPS is perfect), or
     spark profiler start , wait a few minutes, then  spark profiler stop  for a link
     showing what's slow.
