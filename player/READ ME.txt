MONKEY SMP - how to join (players)
===================================

Monkey SMP is a modded Minecraft server. To join, your Minecraft needs the same mods.
This folder sets that up for you. You need Minecraft Java Edition (the one you buy at
minecraft.net) and about 2 GB of free disk space. Option A works on Windows, Mac and
Linux; option B is for Windows 10 or 11 only.


OPTION A: MODRINTH APP OR PRISM LAUNCHER (recommended)
------------------------------------------------------
  Both are free launchers that install the whole pack from one file.
  1. Install one of them: https://modrinth.com/app or https://prismlauncher.org
     Sign in with the Microsoft account you play Minecraft with.
  2. Install the  MonkeySMP-Client-....mrpack  file from this folder:
       Modrinth App:    double-click the file. Or in the app:
                        + (Create new instance)  >  Upload a modpack  >  choose the file.
                        The app asks you to confirm, because the pack is not published
                        on Modrinth yet: choose "Install anyway".
       Prism Launcher:  Add Instance  >  Import  >  choose the .mrpack file
     The launcher downloads the mods and resource packs (about 380 MB).
  3. Give the game 6 GB of memory: in the Modrinth App, the instance's settings >
     "Java and memory"; in Prism Launcher, the instance's Settings > Java.
  4. Press Play. The first start is slow (a few minutes) - that's normal for a modded game.
  5. In the game: Multiplayer > Add Server. Type the server address the host gave you,
     press Done, then Join Server.


OPTION B: THE NORMAL MINECRAFT LAUNCHER (Windows only)
------------------------------------------------------
  1. Start the Minecraft Launcher once, sign in, then CLOSE it.
  2. Double-click  "Install for Minecraft Launcher.bat"  in this folder.
     - Windows may say "Windows protected your PC", because the file is not signed:
       click "More info" then "Run anyway".
     - It downloads the mods and resource packs (about 380 MB) from their official
       websites and checks every file. This takes a few minutes.
     - When it says it's finished, press a key to close the window.
  3. Open the Minecraft Launcher. Next to the green Play button, click the box that says
     the version (e.g. "Latest release") and pick  "Monkey SMP".  Press Play.
     The first start is slow (a few minutes) - that's normal for a modded game.
  4. Add the server as in step 5 of option A.

  Your normal Minecraft is not changed: Monkey SMP keeps its own mods, settings and
  worlds in a separate folder.


BEFORE YOU JOIN
---------------
  Tell the host your exact Minecraft username - only people on the guest list can join.


UPDATING
--------
  When the host sends a newer version, unzip it.
  Option A: install the new .mrpack file the same way as the first one.
  Option B: double-click the installer again. It updates Monkey SMP and keeps your
  settings, worlds and screenshots.


IF SOMETHING GOES WRONG
-----------------------
  "Minecraft Launcher not found"
      Install it from minecraft.net, start it once, sign in, close it, and try again.
  "Monkey SMP" isn't in the launcher
      Close the launcher completely and run the installer again, then reopen the launcher.
  The game is slow or stutters
      Lower Options > Video Settings > Render Distance.
  "Incompatible mods" / can't join the server
      Your version doesn't match the server. Ask the host for the latest player zip.
  Anything else
      Send the host a screenshot of the installer window.


REMOVING IT
-----------
  Double-click  "Uninstall Monkey SMP.bat".  It asks before deleting anything, then
  removes "Monkey SMP" from the launcher and deletes its folder (your normal Minecraft
  is not touched).
