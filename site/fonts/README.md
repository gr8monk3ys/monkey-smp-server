# Fonts

All three are under the SIL Open Font License 1.1 (the `OFL-*.txt` files here), Latin subsets from Google Fonts.

- `pixelify-sans-monkey-bold.woff2`: Pixelify Sans (https://github.com/eifetx/Pixelify-Sans), the variable font
  instanced at weight 700, the only weight the site sets it in. The 5 is redrawn on the font's own grid with a
  square top-left corner, a flat top bar and an open bowl, because Pixelify's 5 is drawn the same as its S
  and the site's prices and countdown are numbers. Renamed "Pixelify Sans Monkey" inside the font, since it is
  a modified version.
- `atkinson-next-latin.woff2`: Atkinson Hyperlegible Next, variable 200 to 800, unmodified. Body text.
- `atkinson-mono-latin.woff2`: Atkinson Hyperlegible Mono, variable 200 to 800, unmodified. The server address
  and commands.
